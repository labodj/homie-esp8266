Welcome to the documentation for the maintained Homie fork used by the LSH ecosystem.

This fork keeps the original Homie for ESP8266 API and flow as intact as possible,
while adding targeted fixes and maintenance for current ESP32 and ESP8266 Arduino
environments. Homie `3.0.1` remains the default MQTT discovery convention, with
Homie `4.0.0` and Homie `5.0` available as opt-in build modes.
